# Бренд Myrmidon

Логотип владельца (28.09.2026): муравей линией, цвет `#0F2940`; надпись MYRMIDON — Montserrat Bold (OFL).

| Файл | Где |
|---|---|
| `myrmidon-mark.svg` | значок (линия 17): шапка, экран входа, значки от 64 px |
| `myrmidon-mark-small.svg` | тот же муравей, линия 30: 24–48 px |
| `myrmidon-mark-tiny.svg` | тот же муравей, линия 40: 16 px |
| `favicon-16x16.png`, `favicon-32x32.png`, `favicon.ico` (16/32/48) | вкладка браузера — уменьшенный тот же муравей |
| `apple-touch-icon.png` (180), `android-chrome-192x192.png`, `android-chrome-512x512.png` | значки приложения |
| `myrmidon-logo-lockup.png` | полный логотип: муравей + MYRMIDON (Montserrat Bold) |
| `source-owner.webp` | исходник владельца (растр, артефакт у правого усика — не использовать напрямую) |

Все размеры — один рисунок (сегменты тела — кривые, сверены наложением с исходником); для
малых размеров только утолщена линия. PNG отрисованы из SVG браузером. Замена значков и имени
в интерфейсе — задача B1 (ROADMAP, 1.1.0).
