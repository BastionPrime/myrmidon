# Бренд Myrmidon

Логотип владельца (28.09.2026): муравей линией + надпись MYRMIDON, цвет `#0F2940`.

| Файл | Где |
|---|---|
| `myrmidon-mark.svg` | значок: шапка, экран входа, значки от 64 px |
| `myrmidon-mark-small.svg` | тот же значок с утолщённой линией для 24–48 px |
| `favicon-16x16.png` | отрисован по пикселям (перетяжки сегментов), не уменьшение |
| `favicon-32x32.png`, `favicon.ico` (16/32/48) | вкладка браузера |
| `apple-touch-icon.png` (180), `android-chrome-192x192.png`, `android-chrome-512x512.png` | значки приложения |
| `myrmidon-logo-lockup.png` | полный логотип (значок + надпись) для документов и README |
| `source-owner.webp` | исходник владельца (растр, есть артефакт у правого усика — не использовать напрямую) |

Значок перерисован в вектор по исходнику; надпись в `myrmidon-logo-lockup.png` взята из исходника
(шрифт не определён — для вектора надписи нужен шрифт или отрисовка). Замена значков и имени в
интерфейсе — задача B1 (ROADMAP, 1.1.0).
