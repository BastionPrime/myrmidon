# Настройки Myrmidon

Наши настройки — переменные окружения `MYRMIDON_<ОБЛАСТЬ>_<ИМЯ>`. Вендорские `PAPERCLIP_*`
остаются как есть и здесь не описываются, кроме случаев, когда мы меняем их смысл или значение
по умолчанию.

**Значения по умолчанию:**

- исправление дефекта включено;
- значения под конкретное развёртывание (окна, лимиты, адреса) выключены или нейтральны.

Наши боевые значения лежат в закрытом `myrmidon-deploy`, не здесь.

Трек пишет только в свой раздел. Строка добавляется в том же PR, что и настройка.

**Колонки:**

- **Переменная** — имя.
- **Функция** — номер функции (`P1`…).
- **По умолчанию** — значение, если переменная не задана.
- **Что делает** — одной фразой.
- **Как выключить / особое** — например, «`0` — без предела».

## Трек 3 — шлюз инструментов и адаптер Hermes

| Переменная | Функция | По умолчанию | Что делает | Как выключить / особое |
|---|---|---|---|---|
| `MYRMIDON_HERMES_RUNTIME_MCP_URL_BASE` | P4 | не задана — адрес шлюза не меняется (как у вендора) | Origin адреса MCP-шлюза прогона `hermes_local` заменяется на этот базовый адрес (например, `http://127.0.0.1:3100`), путь, query и токен сохраняются; в лог пишется только пара origin | Не задавать. На агента: `adapterConfig.runtimeMcpUrlBase` — свой базовый адрес, `adapterConfig.runtimeMcpUrlRewrite: false` — без подмены. | `MYRMIDON_TOOL_BREAKER_COOLDOWN_MS` | P9 | `60000` | Длительность паузы инструмента; после неё проходит один пробный вызов | — |
| `MYRMIDON_TOOL_BREAKER_WINDOW_MS` | P9 | `600000` | Окно, в котором считаются сбои одного инструмента | — |
| `MYRMIDON_TOOL_TIMEOUT_MAX_MS` | P9 | `180000` | Потолок бюджета одного вызова инструмента (у вендора 60 с) | — |
| `MYRMIDON_TOOL_TIMEOUT_SLOW_MS` | P9 | `45000` | Бюджет по умолчанию для навигационных инструментов (`navigate`, `goto`, `click`, `type`, `fill`, `press`, `reload`, `wait` в имени); остальные — 10 с, как у вендора | На подключении: `config.toolTimeouts` — бюджет по имени инструмента |

## Трек 4 — чаты и навыки

| Переменная | Функция | По умолчанию | Что делает | Как выключить / особое |
|---|---|---|---|---|
| `MYRMIDON_TELEGRAM_FILE_LIMIT_BYTES` | P8 | не задана — 25 МБ (как у вендора) | Потолок размера одного файла, который адаптер Telegram скачивает, в байтах. Для своего Bot API — до `2147483648` (2 ГБ) | Не задана, `0`, отрицательное или не число — вендорские 25 МБ. Действующий предел — меньшее из этого значения и `PAPERCLIP_ATTACHMENT_MAX_BYTES`; облачный Bot API сам не отдаёт файлы больше 20 МБ. Читается при создании адаптера — после смены нужен перезапуск |

## Настройки вендора, которые важны для Myrmidon

Здесь — вендорские переключатели, которые нужно знать при развёртывании Myrmidon: например, как
включить режим плана (X2). Заполняют треки, раздел общий.

| Где | Что | Значение для Myrmidon | Функция |
|---|---|---|---|
| `TELEGRAM_API_BASE_URL` | Адрес Bot API для адаптера Telegram (вендорская переменная) | Адрес своего Bot API, если нужны файлы больше 20 МБ; не задана — облачный Bot API | P8 |
| `PAPERCLIP_ATTACHMENT_MAX_BYTES` | Общий предел размера вложения доски (вендор, по умолчанию 10 МБ) | Ограничивает и файлы Telegram: поднять вместе с `MYRMIDON_TELEGRAM_FILE_LIMIT_BYTES` | P8 |
