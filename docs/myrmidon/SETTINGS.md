# Настройки Myrmidon

Наши настройки — переменные окружения `MYRMIDON_<ОБЛАСТЬ>_<ИМЯ>`. Вендорские `PAPERCLIP_*`
остаются как есть и здесь не описываются, кроме случаев, когда мы меняем их смысл или значение
по умолчанию.

**Значения по умолчанию:**

- исправление дефекта включено;
- значения под конкретное развёртывание (окна, лимиты, адреса) выключены или нейтральны.

Наши боевые значения лежат в закрытом `myrmidon-deploy`, не здесь.

Трек пишет только в свой раздел. Строка добавляется в том же PR, что и настройка.

**Колонки:**

- **Переменная** — имя.
- **Функция** — номер функции (`P1`…).
- **По умолчанию** — значение, если переменная не задана.
- **Что делает** — одной фразой.
- **Как выключить / особое** — например, «`0` — без предела».
