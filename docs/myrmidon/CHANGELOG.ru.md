# Журнал изменений Myrmidon

> English version: [CHANGELOG.md](CHANGELOG.md)

Заметки о выпусках Myrmidon, новее сверху. Версия берётся из git-тега
`myr-v<major>.<minor>.<patch>` (CI вшивает её в образ и в `/api/health`); файла версии,
который надо править, нет. Версия Paperclip в основе — в метке образа
`io.github.itkadr-git.myrmidon.base.paperclip-version`. Подробности процедуры выпуска:
[ci.md](ci.md) и [deploy.md](deploy.md).

## 1.2.1

Всё слитое между тегами 1.2.0 и 1.2.1.

### Память и изоляция

- Локальный форк плагина памяти hindsight (`packages/plugins/hindsight-paperclip`, тот же id
  плагина `paperclip-plugin-hindsight`, версия `0.3.0-myrmidon.1`): память каждого агента
  разрешается в его собственный банк из `adapterConfig.hindsight.bankId` карточки или из
  карты `bankByAgentId` конфигурации. Агент без банка закрыт: удержание пропускается с
  предупреждением, а выборка ничего не возвращает — банка по умолчанию нет. Метаданные
  удержания теперь несут имя агента. Установка и обновление — из пути в репозитории; CI
  получил тестовую линию форка и проверки установки на стороне хоста (#150).

### Контейнеры ботов

- Образ бота с Node.js: `/scratch/npm-global/bin` убран из `PATH` — записываемый том в `PATH`
  позволял боту подложить исполняемый файл, и контракт образа dockergate это отклоняет.
  Предустановленные пакеты в `/opt/node-tools` не затронуты; тест Dockerfile теперь проверяет
  `PATH` каждой стадии против политики dockergate (#167).

### Интерфейс

- Фавиконка Myrmidon везде: превью-инстансы ворктри рисуют муравья Myrmidon вместо скрепки
  вендора, а иконки вкладок и веб-манифест отдаются с no-cache, чтобы браузеры их
  перепроверяли (#166).

### Внутреннее

- Набор назначенных агенту инструментов MCP переехал из `heartbeat.ts` в собственный модуль
  (`agent-assigned-tools.ts`) без изменения поведения, чтобы heartbeat и компилятор профиля
  контейнера бота разрешали одно и то же назначение из одного места (#120).

## 1.2.0

Всё слитое после тега 1.1.0, включая исправления, не получившие своего тега.

### Контейнеры ботов

- Свой шлюз инструментов доски у каждого бота: контейнерные боты ходят на доску через свой
  выделенный шлюз.
- Общий сервис медиа-инструментов MCP для контейнерных ботов, с исправлениями инъекции через
  экранирование фильтра, подсчёта квоты каталогов заданий, потоковых конверсий и владения
  spool.
- `dockergate`: прокси Docker со списком разрешённых вызовов для контейнеров ботов.
- Образ бота: вариант с Node.js (`runtime-node`), ssh-клиент и интерпретатор venv для
  пользователя бота.
- Ключи API доски для ботов выдаются с ответственным пользователем.
- Настраиваемый таймаут создания прогона для шлюза hermes (по умолчанию 60 с).
- Тестам сервера больше не нужен настоящий контейнер для обратной связи о запуске контейнера.

### Память и изоляция

- Список разрешённых банков hindsight и области наблюдения в профилях ботов, плюс инструмент
  разделения банков при переносе памяти.
- Вызовы `apiRoute` плагинов привязаны к области вызова.

### Побудки и heartbeat

- Побудки продолжения: исправлены проход по порогу возраста и завершение прямой доставки.
- Задачи, оставленные паузой оператора, будятся пачками при снятии паузы.
- Настраиваемый потолок межзадачного влияния.
- Heartbeat журналирует нечитаемый лимит памяти cgroup; потолок задокументирован.
- Семантика флагов-выключателей покрыта матрицей тестов и стражем документации;
  задокументировано, что перенос бюджета L2 действует только для L1 и что бюджет повторов
  вендора начинается заново у преемника.

### Выкат

- Выкат снимает режим обслуживания при таймауте слива.
- Задокументировано, что миграции базы должны быть только аддитивными.

### Процесс

- Процедура приёма записей в план и сканер текста для записей плана.
- Обёртка сканирования публикаций для текстов PR и задач.
