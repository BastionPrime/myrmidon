# Коннектор alibaba-image: бесплатная генерация и правка изображений для агентов

> Английская версия: [alibaba-image-connector.md](alibaba-image-connector.md)

Коннектор alibaba-image даёт агентам генерацию и правку изображений через
бесплатный ключ Alibaba DashScope компании, рядом с остальными
коннектор-контейнерами (медиа-инструменты, google-ai). Коннектор специфичен
для развёртывания: его код, образ и compose-фрагмент живут в закрытом
репозитории развёртывания в `connectors/alibaba-image/`, а это руководство
описывает эксплуатационную сторону — запуск контейнера в окне выката и
подключение его к ботам. Поток подключения и грантов переиспользует
вендорскую поверхность внешних MCP, описанную в
[external-mcp-connectors.ru.md](external-mcp-connectors.ru.md).

## Что получают боты

| Инструмент | Что делает |
| --- | --- |
| `generate_image(prompt, size, n, model?)` | текст в картинку; модель, размер и `n` (1..4) проверяются по реестру моделей до любого запроса |
| `edit_image(image, instruction, mask?, model?)` | правка картинки по инструкции, опционально с маской |

Модели бесплатного ключа, закреплённые реестром и его тестом
(`test_registry_covers_every_model_on_the_key`): `qwen-image-3.0` (по
умолчанию для генерации), `qwen-image-3.0-pro`, `qwen-image-max`,
`qwen-image-edit-plus` (по умолчанию для правки), `qwen-image-edit-max`,
`wan2.7-image`, `wan2.7-image-pro`, `z-image-turbo`. Размеры генерации —
`1024x1024`, `720x1280`, `1280x720` плюс 1440-варианты там, где модель их
поддерживает; модели правки берут `1024x1024`, `n` всегда 1.

Оба инструмента идут асинхронным контуром DashScope — отправка задачи, затем
опрос до успеха или отказа — с потолком задачи 300 с. Стабильные коды
ошибок, на которые вызывающий может завести ветку: `invalid_model`,
`invalid_size`, `invalid_n`, `invalid_prompt`, `key_unavailable`,
`upstream_error`, `task_failed`, `task_timeout`.

## Результаты и аудит

Файлы кладутся в каталог вызывающей сессии под общим корнем workspace:
`images/<session_id>/image-<ts>-<i>.png` со сайдкаром `result.json` (промпт,
модель, размер, `n`, usage, стоимость 0.0 на бесплатном ключе, sha256 и байты
по каждому файлу). Аудит — дописываемый JSONL-файл в корне workspace; в него
попадают только имена событий и *размеры* аргументов — никогда промпты,
байты картинок или материал ключа.

## Запуск контейнера в окне выката

Коннектор работает своим контейнером из compose-фрагмента репозитория
развёртывания (`connectors/alibaba-image/docker-compose.alibaba-image.yml`)
на порту `8083` (медиа-инструменты занимают 8080, google-ai 8081/8082):

```sh
cd connectors/alibaba-image
docker compose -f docker-compose.alibaba-image.yml up -d
curl http://localhost:8083/tools   # должен показать generate_image и edit_image
```

Два монтирования, оба обязательны:

- ключ DashScope из секретного хранилища доски, bind-монтирование read-only в
  `/run/secrets/dashscope_key` (меняется через `ALI_MCP_KEY_FILE`); ключ
  читается из файла при каждом вызове и не попадает ни в образ, ни в compose,
  ни в логи;
- общий корень workspace агентов (тот же корень, под которым лежат
  workspace ботов, например `/srv/gai-workspaces`) в `/workspace`, чтобы
  сгенерированные файлы оказывались там, где их найдёт вызывающий агент.

Контейнеру нужен исходящий HTTPS на
`https://dashscope-intl.aliyuncs.com`. Ручки сервиса (все необязательные, с
префиксом `ALI_MCP_`): `BASE_URL`, `POLL_INTERVAL_S`, `TASK_TIMEOUT_S`,
`MAX_PROMPT_CHARS`, `WORKSPACE_ROOT`, `KEY_FILE`, `RESULT_DIR`.

## Подключение к ботам

Зарегистрируйте работающий контейнер как внешний MCP-сервер по регламенту
из руководства — plain-HTTP-эндпоинт в частной сети принимается, потому что
инстанс работает с `PAPERCLIP_DEPLOYMENT_MODE=authenticated` и
`PAPERCLIP_DEPLOYMENT_EXPOSURE=private`; не переключайте exposure в `public`,
пока коннектор подключён. Затем выдайте его ровно тем агентам, которым нужны
изображения; гранты на агента по умолчанию запрещены, и не выданный агент не
видит ничего. В этом развёртывании гранты получают дизайн-агенты, дизайнер
работы и SMM-бот; общая регистрация «creative tools» — место, где эти гранты
живут.

Для ботов в контейнерах коннектор можно завести и общей записью
`MYRMIDON_BOT_MCP_SERVERS`, как медиа-инструменты — см.
[../media-tools.md](../media-tools.md); имя контейнера
`alibaba-image-mcp` должно резолвиться из сети ботов.

## Что проверить перед включением

- Файл ключа отвечает и не пуст (пропавший или пустой файл роняет каждый
  вызов с `key_unavailable` до любого запроса наружу).
- Один живой смоук на семейство моделей — генерация на `qwen-image-3.0`, на
  `wan2.7-image`, на `z-image-turbo` и одна правка на `qwen-image-edit-plus`;
  приёмка: агент с грантом генерирует картинку, правит её, и файлы
  оказываются в его workspace.
- Контейнер коннектора стоит в сети, которую сервер доски резолвит и
  достаёт; монтирование workspace указывает на тот же корень, что у ботов.
