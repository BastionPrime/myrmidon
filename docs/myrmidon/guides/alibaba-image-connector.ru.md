# Коннектор alibaba-image: бесплатная генерация и правка изображений для агентов

> Английская версия: [alibaba-image-connector.md](alibaba-image-connector.md)

Коннектор alibaba-image даёт агентам генерацию и правку изображений через
бесплатный ключ Alibaba DashScope компании, рядом с остальными
коннектор-контейнерами (медиа-инструменты, google-ai). Коннектор специфичен
для развёртывания: его код, образ и compose-фрагмент живут в закрытом
репозитории развёртывания в `connectors/alibaba-image/`, а это руководство
описывает эксплуатационную сторону — запуск контейнера в окне выката и
подключение его к ботам. Поток подключения и грантов переиспользует
вендорскую поверхность внешних MCP, описанную в
[external-mcp-connectors.ru.md](external-mcp-connectors.ru.md).

## Что получают боты

| Инструмент | Что делает |
| --- | --- |
| `generate_image(prompt, size, n, model, workspace_dir, agent_id)` | текст в картинку; модель, размер и `n` проверяются по реестру моделей до любого запроса |
| `edit_image(image, instruction, mask, model, size, n, workspace_dir, agent_id)` | правка одной картинки по инструкции или слияние до трёх входных изображений |

Модели бесплатного ключа, закреплённые реестром и его тестом
(`test_registry_covers_every_model_on_the_key`): `qwen-image-3.0` (по
умолчанию для генерации), `qwen-image-3.0-pro`, `qwen-image-max`,
`qwen-image-edit-plus` (по умолчанию для правки), `qwen-image-edit-max`,
`wan2.7-image`, `wan2.7-image-pro`, `z-image-turbo`. Модели Qwen-Image и
Qwen-Image Edit принимают `n` 1–6 (`n>1` — режим вариаций); семейства Wan и
Z-Image — 1–4; `ALI_IMAGE_MAX_IMAGES` ограничивает эффективный потолок для
всего развёртывания (по умолчанию 6). Размеры — свободные `width*height`
(со звёздочкой-разделителем, например `1024*1024`) в пределах границ модели
— 512–2048 по стороне у Qwen и Z-Image, 768–2048 у Wan; семейство Wan также
принимает сокращения `1K`/`2K`/`4K`. `edit_image` принимает `mask` ради
паритета интерфейса, но у правки картинок DashScope параметра маски нет:
результат несёт `mask_note` о том, что маска проигнорирована — она никогда не
теряется молча. Upscale в image-API DashScope не предусмотрен, поэтому
инструмента `upscale` нет.

Оба инструмента идут асинхронным контуром DashScope — отправка задачи, затем
опрос до успеха или отказа — с дедлайном опроса задачи 300 с. Ошибки
приходят машинными кодами самого DashScope с дружелюбным текстом от
коннектора (`InvalidApiKey`, `AuthenticationError`, `Arrearage`,
`Throttling`, `ModelNotExist`, `DataInspectionFailed`,
`IPInfringementSuspect`, `InvalidParameter`, …); локальные сбои валидации
отвечают `invalid_request`, а отсутствующий ключ поднимает `SecretMissing` с
сообщением, называющим только настроенные места ключа, никогда — значение.

## Результаты и аудит

Каждая картинка пишется в workspace вызывающего как
`<model>-<utc-timestamp>-<i>.png`, с одним сайдкаром
`<model>-<utc-timestamp>.json` на вызов: инструмент, агент, модель,
промпт/инструкция, размер, `n`, request id, блок `usage` DashScope и
метаданные стоимости. Стоимость остаётся честной: без записи о цене в
`ALI_IMAGE_PRICES` оценка равна `estimated_cost_usd: null` с
`pricing_source: "unset"` — коннектор никогда не выдумывает цену. Аудит —
дописываемый JSONL-файл (одна строка на вызов с id агента, *размерами*
аргументов, статусом и задержкой) — никогда содержимое промптов или
инструкций, никогда материал ключа.

## Запуск контейнера в окне выката

Коннектор работает своим контейнером из compose-фрагмента репозитория
развёртывания (`connectors/alibaba-image/docker-compose.alibaba-image.yml`),
слитого в compose-развёртывание доски; внутри контейнера он слушает
`0.0.0.0:8083`, наружу публикуется на `127.0.0.1:8083`:

```sh
docker compose -f connectors/alibaba-image/docker-compose.alibaba-image.yml up -d
```

Пробой служит streamable-HTTP-эндпоинт (`/mcp`, JSON-RPC `tools/list`), а не
URL `/tools`; точные `tools/call`-нагрузки по семействам моделей — в секции
живого смоука репозитория развёртывания.

Два монтирования и один том:

- ключ DashScope из секретного хранилища доски, bind-монтирование read-only в
  `/run/secrets/dashscope_api_key` (читаемость для uid 1000; источник
  меняется `ALI_IMAGE_KEY_FILE` в окружении compose, внутриконтейнерный путь
  — `ALI_IMAGE_API_KEY_FILE`); ключ читается при каждом вызове — сначала из
  смонтированного файла, затем из переменной окружения `DASHSCOPE_API_KEY` —
  поэтому ротация секрета доски подхватывается без перезапуска, и ключ не
  попадает ни в образ, ни в compose, ни в логи, ни в вывод инструментов;
- общий корень workspace агентов (тот же корень, под которым лежат
  workspace ботов; умолчание compose — `/srv/ali-image-workspaces`,
  переопределяется `ALI_IMAGE_WORKSPACE_ROOT`) в `/workspace`, чтобы
  сгенерированные файлы оказывались там, где их найдёт вызывающий агент;
- именованный том `ali-image-data` на `/data` хранит JSONL-журнал аудита.

Контейнеру нужен исходящий HTTPS на эндпоинт региона —
`https://dashscope-intl.aliyuncs.com/api/v1` (Сингапур, по умолчанию) или
`https://dashscope.aliyuncs.com/api/v1` (Пекин); ключи между регионами не
взаимозаменяемы, и смонтированный ключ должен соответствовать настроенному
эндпоинту.

Ручки сервиса (все необязательные, с префиксом `ALI_IMAGE_`): `BASE_URL`,
`API_KEY_FILE`, `API_KEY_ENV`, `AUDIT_PATH`, `WORKSPACE_DIR`, `AGENT_ID`,
`DEFAULT_MODEL`, `REQUEST_TIMEOUT` (HTTP, по умолчанию 600 с),
`POLL_INTERVAL` (по умолчанию 5 с), `POLL_TIMEOUT` (по умолчанию 300 с),
`MAX_IMAGES`, `PRICES`, `MCP_HOST`, `MCP_PORT`.

## Подключение к ботам

Зарегистрируйте работающий контейнер как внешний MCP-сервер по регламенту из
руководства — одна удалённая connection (`transport: mcp_remote`, эндпоинт
`http://alibaba-image-mcp:8083/`) в сети доски; учётных данных на стороне
доски не вводится, потому что ключ DashScope живёт в собственном
смонтированном секрете коннектора. Plain-HTTP-эндпоинт в частной сети
принимается, потому что инстанс работает с
`PAPERCLIP_DEPLOYMENT_MODE=authenticated` и
`PAPERCLIP_DEPLOYMENT_EXPOSURE=private`; не переключайте exposure в `public`,
пока коннектор подключён. Затем выдайте его ровно тем агентам, которым нужны
изображения; гранты на агента по умолчанию запрещены, и не выданный агент не
видит ничего. В этом развёртывании гранты получают дизайнер работы, SMM bbq и
дизайн-агенты; общая регистрация «creative tools» — место, где эти гранты
живут.

Для ботов в контейнерах коннектор можно завести и общей записью
`MYRMIDON_BOT_MCP_SERVERS`, как медиа-инструменты — см.
[../media-tools.md](../media-tools.md); имя контейнера
`alibaba-image-mcp` должно резолвиться из сети ботов.

## Что проверить перед включением

- Файл ключа отвечает и не пуст (пропавший или пустой ключ роняет каждый
  вызов с `SecretMissing` до любого запроса наружу).
- Один живой смоук на семейство моделей — генерация на `qwen-image-3.0`, на
  `wan2.7-image-pro`, на `z-image-turbo` и одна правка на
  `qwen-image-edit-plus`; приёмка: каждый вызов возвращает непустые
  `image_paths` и `metadata_path`, и файлы существуют в workspace агента с
  соответствующим блоком `usage`.
- Контейнер коннектора стоит в сети, которую сервер доски резолвит и
  достаёт; монтирование workspace указывает на тот же корень, что у ботов.
