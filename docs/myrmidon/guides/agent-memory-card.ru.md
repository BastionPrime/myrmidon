# Память агента: вкладка Memory в карточке агента

> English version: [agent-memory-card.md](agent-memory-card.md)

Вкладка **Memory** в карточке агента показывает записи банка памяти агента —
того самого банка, в который плагин памяти пишет во время прогонов. Из вкладки
оператор может просматривать записи, выгружать весь банк в JSON, удалять
отдельную запись и очищать весь банк. Вкладка живёт в блоке **Runtime**
навигации карточки агента.

## Когда вкладка работает

Секцию включают две настройки инстанса; нужны обе:

- `MYRMIDON_HINDSIGHT_API_URL` — базовый адрес общего сервиса памяти
  (hindsight), как его видит сервер доски.
- `MYRMIDON_HINDSIGHT_KEY_SECRET` — имя секрета компании, в котором лежит ключ
  API сервиса памяти.

Точная семантика — в [SETTINGS.md](../SETTINGS.ru.md). Настройки читаются на
каждый запрос: их изменение действует без перезапуска.

Пока одна из настроек не задана, вкладка показывает строку статуса «Agent
memory is not enabled on this instance.», а её маршруты данных отвечают 503.
Настройки общие на весь инстанс; сам банк памяти резолвится для каждого агента
отдельно.

## Чей банк показывает вкладка

Вкладка показывает банк, который агент реально использует, по тому же правилу,
что применяет форк плагина памяти:

1. `adapterConfig.hindsight.bankId` карточки агента, иначе
2. запись об агенте в карте `bankByAgentId` конфигурации плагина памяти, иначе
3. у агента нет банка — вкладка показывает «This agent has no memory bank
   configured» (это состояние, а не ошибка).

Оператор не может направить вкладку на банк, который агент не использует.

## Что умеет вкладка

- **Список записей.** Пятьдесят записей на страницу, листание **Newer** /
  **Older**. Каждая запись показывает текст, тип факта, состояние (показывается,
  когда не `valid`), дату и теги.
- **Выгрузка банка.** Скачивает весь банк одним JSON-файлом
  (`agent-<agent-id>-memory.json`). Банк больше 5000 записей обрезается до
  5000, и уведомление сообщает, сколько записей выгружено из общего числа.
- **Удаление записи.** У каждой записи, которая ещё не инвалидирована, есть
  поле причины и кнопка **Remove**; кнопка неактивна, пока причина не введена.
  Удаление — мягкая инвалидация с этой причиной: запись остаётся в аудите
  сервиса как инвалидированная, и удаление там обратимо. Инвалидированные
  записи список показывает с их состоянием, без элементов управления
  удалением.
- **Очистка всего банка.** Деструктивное действие в отдельном блоке: оно
  активируется только после ввода идентификатора агента в поле подтверждения.
  Уведомление о результате сообщает, сколько записей удалено.

Вкладкой может пользоваться только board-актёр с доступом к компании агента;
ключ агента не может ни читать, ни менять никакой банк памяти, а агент чужой
компании неотличим от отсутствующего (404).

## Журнал активности

Каждая выгрузка, удаление и очистка банка пишет строку в журнал активности
компании с действием семейства `myrmidon.agent.memory.*`. В строке — id банка,
id записи и причина удаления, где это применимо, — но никогда тексты самих
записей памяти.
