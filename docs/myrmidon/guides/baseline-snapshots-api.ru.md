# API Снимков Базовой Линии

API снимков базовой линии позволяет создавать и управлять замороженными метриками для целей сравнения. Эти снимки фиксируют метрики базовой линии для определенного временного окна и могут быть помечены и закреплены для удобства ссылки.

## Эндпоинты

### POST /api/myrmidon/companies/:companyId/baseline/snapshots

Создает новый снимок метрик базовой линии для указанной компании.

#### Аутентификация
- Требуется аутентификация пользователя доски (ключам агента будет возвращен 403 Forbidden)
- Требуется валидация доступа к компании

#### Тело запроса
```json
{
  "from": "2023-01-01T00:00:00Z",
  "to": "2023-01-31T23:59:59Z",
  "label": "январь-2023-базовая-линия",
  "pinned": true
}
```

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| from | строка (ISO 8601) | Да | Дата начала временного окна |
| to | строка (ISO 8601) | Да | Дата окончания временного окна |
| label | строка | Нет | Опциональная метка для снимка |
| pinned | булевое | Нет | Признак закрепления снимка (по умолчанию: false) |

#### Ответ
- Статус: `201 Created`
- Content-Type: `application/json`

```json
{
  "id": "uuid-строка",
  "companyId": "uuid-строка",
  "windowFrom": "2023-01-01T00:00:00.000Z",
  "windowTo": "2023-01-31T23:59:59.000Z",
  "generatedAt": "2023-02-01T10:00:00.000Z",
  "label": "январь-2023-базовая-линия",
  "pinned": true
}
```

#### Поведение
- Вычисляет метрики базовой линии для указанного временного окна с использованием той же логики, что и эндпоинт метрик
- Сохраняет вычисленные метрики как замороженный снимок в базе данных
- Если `pinned` равно true, автоматически открепляет любой предыдущий закрепленный снимок для компании
- Только один снимок может быть закреплен для каждой компании одновременно

### GET /api/myrmidon/companies/:companyId/baseline/snapshots

Получает все снимки базовой линии для указанной компании.

#### Аутентификация
- Требуется валидация доступа к компании

#### Ответ
- Статус: `200 OK`
- Content-Type: `application/json`

```json
[
  {
    "id": "uuid-строка",
    "companyId": "uuid-строка",
    "windowFrom": "2023-01-01T00:00:00.000Z",
    "windowTo": "2023-01-31T23:59:59.000Z",
    "generatedAt": "2023-02-01T10:00:00.000Z",
    "label": "январь-2023-базовая-линия",
    "pinned": true
  },
  {
    "id": "uuid-строка",
    "companyId": "uuid-строка",
    "windowFrom": "2023-02-01T00:00:00.000Z",
    "windowTo": "2023-02-28T23:59:59.000Z",
    "generatedAt": "2023-03-01T10:00:00.000Z",
    "label": "февраль-2023-базовая-линия",
    "pinned": false
  }
]
```

### GET /api/myrmidon/companies/:companyId/baseline/snapshots/:snapshotId

Получает конкретный снимок базовой линии по ID.

#### Аутентификация
- Требуется валидация доступа к компании

#### Параметры
- `snapshotId`: UUID конкретного снимка для получения

#### Ответ
- Статус: `200 OK`
- Content-Type: `application/json`

```json
{
  "id": "uuid-строка",
  "companyId": "uuid-строка",
  "windowFrom": "2023-01-01T00:00:00.000Z",
  "windowTo": "2023-01-31T23:59:59.000Z",
  "generatedAt": "2023-02-01T10:00:00.000Z",
  "label": "январь-2023-базовая-линия",
  "pinned": true,
  "payload": {
    // Полный пейлоад метрик базовой линии, как возвращаемый эндпоинтом метрик
    "window": {
      "from": "2023-01-01T00:00:00.000Z",
      "to": "2023-01-31T23:59:59.000Z"
    },
    "generatedAt": "2023-02-01T10:00:00.000Z",
    "source": {
      "statusLog": "activity_log",
      "costs": "litellm_cost_events"
    },
    "byProject": [...],
    "byRole": [...]
  }
}
```

## Сценарии использования

### Создание базовой линии перед изменениями
Создайте снимок перед внедрением изменений для сравнения метрик после:

```bash
curl -X POST \
  -H "Authorization: Bearer BOARD_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "2023-01-01T00:00:00Z",
    "to": "2023-01-31T23:59:59Z",
    "label": "pre-change-baseline",
    "pinned": true
  }' \
  "http://localhost:3100/api/myrmidon/companies/COMPANY_ID/baseline/snapshots"
```

### Сравнение метрик во времени
Получите снимки для сравнения метрик из разных периодов:

```bash
curl -H "Authorization: Bearer BOARD_TOKEN" \
  "http://localhost:3100/api/myrmidon/companies/COMPANY_ID/baseline/snapshots"
```

## Детали реализации

- Снимки хранятся в таблице `baseline_metric_snapshots`
- Каждый снимок содержит полный пейлоад метрик для указанного временного окна
- Поле `pinned` позволяет отметить конкретный снимок как контрольную точку
- Только пользователи доски могут создавать снимки (ключи агентов получают 403 Forbidden)
- Когда новый снимок закрепляется, любой предыдущий закрепленный снимок для той же компании автоматически открепляется
