# API снимков базовой линии

API снимков базовой линии позволяет создавать и управлять замороженными снимками метрик для целей сравнения. Эти снимки фиксируют базовые метрики для конкретного временного окна и могут использоваться как контрольные точки для сравнения с пилотными измерениями.

## Обзор

API снимков базовой линии предоставляет следующие возможности:

- Создание снимков базовых метрик для произвольных временных окон
- Маркировка снимков для идентификации
- Закрепление снимков как контрольных точек
- Получение списков снимков
- Получение отдельных снимков по ID

## API эндпоинты

### POST /api/myrmidon/companies/:companyId/baseline/snapshots

Создает новый снимок базовой линии для указанной компании.

#### Запрос

**Заголовки:**
- `Authorization: Bearer <board_token>` (Обязательно: только администраторы доски)

**Тело:**
```json
{
  "from": "2026-09-19T08:28:00.000Z",
  "to": "2026-10-03T08:28:00.000Z",
  "label": "Базовая линия Q3 2026",
  "pinned": true
}
```

**Параметры:**
- `from` (string): Время начала в формате ISO 8601
- `to` (string): Время окончания в формате ISO 8601
- `label` (string): Человекочитаемая метка для снимка
- `pinned` (boolean): Закреплен ли снимок как контрольная точка

#### Ответ

**Успешно (201 Created):**
```json
{
  "id": "a1b2c3d4-e5f6-7890-1234-567890abcdef",
  "companyId": "company-uuid",
  "windowFrom": "2026-09-19T08:28:00.000Z",
  "windowTo": "2026-10-03T08:28:00.000Z",
  "generatedAt": "2026-10-04T10:00:00.000Z",
  "label": "Базовая линия Q3 2026",
  "pinned": true,
  "payload": {
    "window": { "from": "2026-09-19T08:28:00.000Z", "to": "2026-10-03T08:28:00.000Z" },
    "source": { "statusLog": "activity_log", "costs": "litellm_cost_events" },
    "byProject": [],
    "byRole": []
  }
}
```

`payload` — полный ответ метрик, посчитанный тем же `computeBaselineMetrics`,
который использует эндпоинт `GET …/baseline/metrics`; та же форма, замороженная
в момент создания.

**Ошибки:**
- `403 Forbidden`: Использован токен агента (требуется доступ администратора)
- `400 Bad Request`: Неверные параметры (отсутствуют или не парсятся `from`/`to`, или `from` позже `to`)

Получает конкретный снимок базовой линии по ID.

#### Запрос

**Заголовки:**
- `Authorization: Bearer ***

#### Ответ

**Успешно (200 OK):**
```json
{
  "id": "a1b2c3d4-e5f6-7890-1234-567890abcdef",
  "companyId": "company-uuid",
  "windowFrom": "2026-09-19T08:28:00.000Z",
  "windowTo": "2026-10-03T08:28:00.000Z",
  "generatedAt": "2026-10-04T10:00:00.000Z",

  "pinned": true,

}
```

**Ошибки:**
- `404 Not Found`: Снимок с указанным ID не существует для этой компании

## Логика закрепления

API обеспечивает следующую логику закрепления:
- Только один снимок может быть закреплен для каждой компании в любой момент времени
- Когда новый снимок создается с `pinned: true`, любой ранее закрепленный снимок для этой компании автоматически открепляется
- Разрешено создавать несколько снимков с `pinned: false`

## Аутентификация и авторизация

- Для создания снимков требуется доступ администратора доски (токены доски)
- Чтение снимков доступно любому владельцу действительного токена
- Токены агентов отклоняются при создании снимков с ответом 403 Forbidden

## Пример использования

Создание снимка для периода между 19 сентября 2026 года и 3 октября 2026 года:

```bash
curl -X POST \
  https://your-domain.com/api/myrmidon/companies/your-company-id/baseline/snapshots \
  -H 'Authorization: Bearer your-board-token' \
  -H 'Content-Type: application/json' \
  -d '{
    "from": "2026-09-19T08:28:00.000Z",
    "to": "2026-10-03T08:28:00.000Z",
    "label": "Базовая линия до пилота",
    "pinned": true
  }'
```
