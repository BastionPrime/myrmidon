# Хаб доступов (Access hub)

> English version: [access-hub.md](access-hub.md)

Access hub — раздел настроек (Настройки → Access hub, маршрут
`company/settings/access-hub`, пункт бокового меню сразу после Secrets), который
даёт оператору общий вид секретов, которыми пользуются агенты, хосты и сервисы:
кто держит реквизиты, где они используются, когда их последний раз меняли. С
того же экрана оператор создаёт секреты, меняет их значения, выдаёт и отзывает
доступ агентам, ротирует секреты с перезапуском контейнеров, генерирует
SSH-ключи и читает журнал.

Раздел использует тот же ключ видимости оператора, что и Secrets: пункт
появляется в боковом меню настроек только там, где видна сама страница Secrets.

## Единственное правило секретности

Значения секретов не отображаются никогда. Список, карточка и журнал
показывают только имена, ссылки, версии и публичный отпечаток SSH — колонки со
значением нет нигде в разделе. Единственный кусочек материала реквизитов,
который интерфейс вообще показывает, — публичная половина только что
сгенерированной пары SSH-ключей: она держится в памяти страницы, пока открыта
её карточка (или диалог генерации), а повторно открытая карточка показывает
только отпечаток. Значение, введённое в диалог записи, отправляется один раз,
никогда не возвращается из API и стирается из формы, как только сохранение
завершается.

## Список доступов

Список показывает все доступы, которые сообщает сервер, по строке на доступ:

| Колонка | Содержимое |
|---|---|
| Name | Имя и ключ доступа |
| Type | `SSH key`, `Password`, `Token` или `OAuth` |
| Granted to | Агенты, которым доступ выдан |
| Used by | Хосты и сервисы, которые его используют |
| Created | Время создания (UTC) |
| Rotated | Время последней ротации (UTC), `—`, если ни разу |
| Version | Номер текущей версии, `v<N>` |

Список фильтруется свободным поиском (имя, ключ, имена держателей и
использований), по типу и по агенту, которому доступ выдан.

## Карточка доступа

Открытие строки показывает карточку с полной картиной одного доступа: версия,
время создания и последней ротации, публичный отпечаток SSH для ключей, агенты,
которым доступ выдан, хосты и сервисы, которые его используют (с путём
конфигурации, где стоит ссылка), и набор хостов. Поля со значением в карточке
нет.

Действия в карточке:

- **Change value** — заменить значение секрета. Новое значение вводится в
  диалог, отправляется один раз и никогда не показывается обратно.
- **Rotate** — ротировать доступ (см. ниже).
- **Generate SSH key** — для SSH-доступов сгенерировать новую пару ключей
  (см. ниже).
- **Deploy to hosts** / **Withdraw from hosts** — изменить набор хостов
  парка, на которых лежит этот доступ.
- **Grant** / **Revoke** — выдать доступ агенту или отозвать его. Выдача —
  это ссылка: агент получает доступ к секрету, а не копию его значения.

## Ротация с перезапуском

У диалога ротации два режима:

- **External source** — значение изменилось вне Myrmidon; сервер записывает
  новую версию без введённого значения.
- **New value** — введите новое значение; оно записывается один раз и никогда
  не возвращается.

В обоих режимах есть «Restart the containers that use this access» (включено
по умолчанию). Затронутые контейнеры перезапускаются один за другим в коротком
окне обслуживания, и каждый перезапущенный контейнер получает новое значение.
Всплывающее уведомление о результате сообщает номер новой версии и имена
перезапущенных контейнеров.

## Генерация SSH-ключа

Диалог генерации создаёт новую пару SSH-ключей как доступ. Дайте ключу имя и
при желании выберите хосты из реестра хостов парка: генерация и раскладка —
один шаг, и выбранные хосты получают новый публичный ключ тем же вызовом.

Публичная половина и её отпечаток показываются один раз, в этом диалоге, —
скопируйте публичный ключ на каждый выбранный хост сразу. На карточке после
этого остаётся только отпечаток; повторно открытая карточка показывает один
лишь отпечаток. На хост попадает только публичная половина SSH-ключа.

## Журнал

Таб «Журнал» показывает, кто какого доступа коснулся, когда и какая версия из
этого вышла: создание, выдача, отзыв, ротация и раскладка доступов попадают
сюда. Строки журнала несут имена и версии — никогда значения. Таб показывает
50 последних строк.

## API

Раздел обращается к API хаба доступов по адресу `/api/myrmidon/access-hub`
(`GET /accesses`, `POST /secrets`, `POST /secrets/generate-ssh`,
`POST /accesses/:id/grant`, `POST /accesses/:id/revoke`,
`POST /accesses/:id/rotate`, `PUT /accesses/:id/hosts`, `GET /hosts`,
`PUT /hosts`, `GET /audit`). Значения секретов никогда не уходят обратно по
этому API: записи не несут поля значения, а единственное введённое оператором
значение записи никогда не возвращается в ответе. Раскладка и снятие
записывают набор хостов записи через `PUT /accesses/:id/hosts`, рядом с
реестром хостов, который уже даёт API.
