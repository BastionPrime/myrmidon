# Контейнер бота: раздел «Container» карточки агента

> English version: [bot-container-card.md](bot-container-card.md)

Агент с адаптером `hermes_gateway` может работать внутри Docker-контейнера,
управляемого доской. Раздел **Container** карточки хранит настройки и показывает
текущее состояние этого контейнера.

## Что содержит раздел

| Поле | Что задаёт |
|---|---|
| **Enabled** | Создаёт ли доска и поддерживает ли контейнер для этого агента. |
| **Image** | Образ контейнера. Должен быть в списке разрешённых образов инстанса. |
| **Memory, MB** | Лимит памяти контейнера. |
| **CPUs** | Лимит CPU контейнера. |
| **PIDs limit** | Максимальное число процессов внутри контейнера. |
| **Group** | Группа контейнера (пока не поддерживается; показывает предупреждение). |

Дополнительные каталоги хоста, монтируемые только для чтения, задаются
JSON-настройкой карточки `adapterConfig.container.extraMounts` — см.
[bot-extra-mounts.ru.md](../bot-extra-mounts.ru.md).

Раздел отсутствует для адаптеров, отличных от `hermes_gateway`, и при создании
агента.

## Concurrent runs limit

Политика планирования карточки (`runtimeConfig.heartbeat.maxConcurrentRuns`)
задаёт, сколько прогонов этого агента может быть активно одновременно. Доска
нормализует значение в диапазон 1–50 (по умолчанию — встроенное значение
платформы) и записывает его в `config.yaml` бота как
`gateway.api_server.max_concurrent_runs`.

Блок **Concurrent runs limit** сравнивает то, что просит доска, с тем, что
реально получил шлюз бота:

- **Board** — нормализованное значение карточки.
- **Gateway** — значение, записанное в маркере применённого профиля контейнера
  (`applied.json`), или **not reported yet**, когда маркер не несёт числа
  (контейнер создан до того, как это поле появилось, или маркер нечитаем).
  Следующий проход сверки перезаписывает маркер без перезапуска шлюза.

Когда значения различаются, блок показывает бейдж **Diverged from the board**.
Расхождение означает, что шлюз работает с другим лимитом, чем просит карточка;
следующее применение профиля (сверка или **Apply now**) возвращает их в синхрон.

### Шлюз не управляется доской

Для агента, чей шлюз работает вне контейнеров доски (контейнеры выключены на
карточке или в инстансе нет бот-контейнеров), блок показывает **Gateway: not
managed by the board**. Доска не может прочитать или применить лимит внешнего
шлюза; она показывает только значение карточки.

Если лимит доски выше 1 и прогоны этого агента недавно получали от шлюза ответ
HTTP 429, блок также показывает предупреждение: шлюз удерживает прогоны ниже
того, что просит карточка.

## Apply now

Кнопка **Apply now** запускает немедленный проход сверки для контейнера этого
агента: профиль пересобирается из текущей карточки и записывается в контейнер.
Используйте её после правки карточки, когда не хотите ждать следующего
периодического прохода.

Проход — запущенный кнопкой **Apply now** или периодической сверкой —
перечитывает карточку агента в момент прохода, под локом бота, и собирает spec
из этой свежей карточки, а не из снимка, снятого раньше. Правку карточки,
за которой следует **Apply now**, нельзя отменить проходом сверки, начавшимся
до правки: проходы одного бота упорядочены локом, и более поздний проход видит
карточку такой, какая она есть в этот момент, поэтому применяемый шаблон
всегда текущий.

Карточку, которую в момент прохода больше нельзя прочитать, проход роняет
(**error**), а не откатывается молча на старый снимок; следующий проход
повторяет попытку. Карточка, переставшая подходить под контейнер (контейнеры
выключены, другой адаптер, недопустимые лимиты), делает проход **not
applicable** — тот же ответ, как если бы такую карточку передали в **Apply
now**.

Канарейка образа бота ведёт образ раскатки через тот же проход: образ раскатки
подменяет образ карточки на этот проход (`specImage`), а лимиты и монтирования
по-прежнему берутся из свежепрочитанной карточки — подмена переживает свежее
чтение. См. [design/bot-canary.md](../design/bot-canary.md).

## Статус и ошибки

Раздел показывает состояние контейнера подписью: **Running**, **Stopped**,
**Unhealthy** или **Not created yet**. Рядом показывается образ.

Когда рантайм контейнера не отвечает, раздел показывает
**Container status unavailable: …**, а блок **Concurrent runs limit**
исчезает целиком — сравнение невозможно без применённого состояния для чтения.
