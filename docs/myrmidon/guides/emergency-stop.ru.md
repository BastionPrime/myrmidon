# Аварийная остановка прогонов осушаемой паузы

> English version: [emergency-stop.md](emergency-stop.md)

Аварийная остановка — немедленный рычаг оператора для прогонов, которые
осушаемая пауза оставила дорабатывать. Она появилась в выпуске 1.1.2 (пункт
плана 2.2-17, строка доски L3b-ES) и не требует настройки: ни новых переменных
окружения, ни настроек.

## Зачем она нужна

С L3 пауза оператора по умолчанию осушает (`MYRMIDON_PAUSE_DRAINS`, включена,
пока явно не выключена): активные прогоны дорабатывают до конца, поэтому пауза
не производит стену замков разбора. Это правильное умолчание для выкатов и
ночей — но когда ушедшего вразнос агента нужно остановить *сейчас*, единственным
немедленным рычагом был `POST /agents/:id/pause` с `cancelActive: true`,
который заодно переворачивает статус агента и недоступен из интерфейса доски.
Аварийная остановка — это отдельное действие «остановить прогоны».

## Как пользоваться из доски

Откройте страницу агента. Пока агент на паузе **и** у него ещё есть живые
прогоны (`queued`, `running`, `scheduled_retry`), на странице висит баннер со
счётом дорабатывающих прогонов и кнопкой **Аварийный стоп**. Кнопка открывает
диалог подтверждения; подтверждение вызывает маршрут остановки, а тост
сообщает, сколько прогонов отменено. Баннер исчезает, как только живых прогонов
не остаётся или агент снят с паузы — живые прогоны активного агента это его
обычная работа: сначала пауза, потом остановка.

Строки баннера локализованы (ключи `emergencyStopBanner.*` во всех файлах
локалей; русский перевод полный, остальные локали несут английскую базу до
перевода).

## Как пользоваться через API

```sh
curl -X POST https://board.example.com/api/myrmidon/agents/<agent-id>/emergency-stop \
  -H "Authorization: Bearer <board-api-key>"
```

Ответ сообщает счёт:

```json
{ "agentId": "<agent-id>", "runsCancelled": 3 }
```

Правила доступа те же, что у маршрута паузы: board-актор с доступом к компании
агента и грантом `agents:create`. Ключ самого агента получает 403; участник
доски с правом только чтения — тоже 403. Неизвестный id агента и агент чужой
компании получают одинаковый 404, так что перебирать id агентов между
компаниями нельзя.

## Что остановка делает и чего не делает

- Она отменяет отменяемые прогоны агента (`queued`, `running`,
  `scheduled_retry`) через тот же вызов `heartbeat.cancelActiveForAgent`, что и
  явная отмена при паузе, с тем же кодом ошибки `agent_paused` —
  инфраструктурное прерывание, поэтому без замка
  `legacy_execution_requires_reconciliation` и без немедленной эскалации
  зависшей задачи (поведение L1, ограниченный бюджет повторов).
- Она **не** меняет статус самого агента: агент на паузе остаётся на паузе,
  активный остаётся активным. Остановить прогоны — отдельное действие, не
  «поставить на паузу»; объединить их умеет маршрут паузы с
  `cancelActive: true`.
- Отмену нельзя откатить, но работа не теряется: при снятии паузы затронутые
  задачи будит обычный путь L3.
- Принятая гонка: поскольку маршрут не трогает статус агента, он может
  пересечься со снятием паузы или свежей побудкой в тот же момент. Прогоны,
  стартовавшие после снимка отмены, просто не отменяются — нажмите кнопку ещё
  раз. Прогоны, отменённые как раз перед снятием паузы, будит обычный путь L3.
  Ни тот, ни другой исход не теряет работу и не портит состояние.

Каждая остановка пишет в журнал активности запись
`myrmidon.agent.emergency_stop` с числом отменённых прогонов.

## Заметки оператору

- Настраивать нечего: ни переменная `MYRMIDON_*`, ни флаг не управляют ни
  маршрутом, ни баннером. Осушение паузы, от которого остановка становится
  нужной, регулирует `MYRMIDON_PAUSE_DRAINS` (см. [../SETTINGS.md](../SETTINGS.md)
  и [../FLAGS.md](../FLAGS.md)); сама аварийная остановка работает независимо от
  этой настройки, но живые прогоны на паузе оставляет только осушаемая пауза.
- Строка доски — L3b-ES в [../DIVERGENCE.md](../DIVERGENCE.md); маршрут
  смонтирован по адресу `/api/myrmidon/agents/:id/emergency-stop` в
  `server/src/app.ts`, модуль — `server/src/myrmidon/emergency-stop.ts`,
  баннер — `ui/src/components/myrmidon/EmergencyStopBanner.tsx`.
