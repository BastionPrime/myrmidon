# Расширение браузерного моста (части C и D)

> English version: [bridge-extension.md](bridge-extension.md)

Браузерный мост даёт боту компании глаза и руки в браузере на клиентском ПК:
open, read, click, fill, download, screenshot и шаг подтверждения, который
отвечает человек за этим ПК. У моста две стороны. Сторона шлюза (часть B) живёт
на доске; сторона расширения (части C и D) — расширение Chrome/Edge в каталоге
[`extension/`](../../../extension/). Записанные сценарии конкретной площадки
строятся поверх этих примитивов и здесь не лежат.

## Что такое расширение

Расширение Manifest V3 (`extension/manifest.json`), самостоятельный npm-пакет
вне pnpm-workspace (`@myrmidon/extension`, private). Оно открывает ровно одно
исходящее соединение — WSS-клиент к шлюзу моста — и не открывает входящих
портов. Разрешения минимальны: `storage`, `tabs` и доступ к хостам `wss://*/*`.
Всё, что исполняет расширение, лежит в этом репозитории; удалённого кода нет.

Проводной контракт — JSON-RPC 2.0, зеркально скопированный со шлюза в
`extension/src/protocol.ts` (оригинал,
`packages/shared/src/myrmidon-browser-bridge.ts`, придёт с частью B; при
изменении контракта шлюза меняются оба файла синхронно). Рукопожатие —
`bridge.hello` → `bridge.ready`; шлюз объявляет версию протокола и список
разрешённых доменов компании в `bridge.ready`.

## Действия

Шесть методов: `browser.open`, `browser.read`, `browser.click`, `browser.fill`,
`browser.download`, `browser.screenshot` (`extension/src/actions.ts`,
`EXTENSION_CAPABILITIES`). Проверка capability идёт на шлюзе и повторно локально
в расширении, запрет по умолчанию.

- `browser.open` / `browser.read` / `browser.click` — переход, видимый текст
  страницы и клик по селектору.
- `browser.fill` — ввод значения в одно поле (input, textarea, select или
  contenteditable) с отправкой `input`/`change`, чтобы страница, слушающая эти
  события, увидела изменение. Любой другой элемент отклоняется.
- `browser.download` — файл тянется в сессии самой страницы (content script
  работает в origin страницы, поэтому запрос несёт cookie, которые у браузера
  человека уже есть); боту возвращаются имя, тип, размер и байты (base64). Мост
  несёт не больше `BROWSER_DOWNLOAD_MAX_BYTES` (25 МиБ); больший файл
  отклоняется кодом `downloadTooLarge`.
- `browser.screenshot` — видимая вкладка как PNG data url.

Каждое действие проходит локальный гейт списка разрешённого
(`extension/src/allowlist.ts`) до обращения к любому API браузера: расширение
держит свою копию списка доменов компании и сопоставляет целевой хост как сам
домен или его поддомен. Шлюз проверяет ещё раз — эшелонированная защита.

Метода подписи нет. Расширение никогда не подписывает само: локальный хелпер
держит ключ и PIN, и расширение не объявляет capability `sign` вообще.

## Подтверждение

Действие, помеченное шлюзом `confirmation: "human"`, выполняется только после
подтверждения человеком на клиентском ПК. Расширение открывает небольшую
страницу расширения (`confirm/confirm.html`) с одной строкой — действие и его
цель — и кнопками Confirm и Refuse. Отказ — это ошибка `confirmationNotGranted`,
и действие не выполняется.

Бюджет держит шлюз: он удерживает запрос 180 с и, если никто не ответил,
присылает нотификацию `browser.cancel` с id запроса. Расширение сбрасывает этот
ожидающий шаг и закрывает окно, поэтому шаг, который человек не подтвердил,
не сработает позже. Тот же путь обслуживает любое подтверждаемое действие, не
только шаги подписи.

## Сопряжение

1. Оператор компании создаёт одноразовый код сопряжения в панели моста (время
   жизни — 15 минут) и диктует его человеку у клиентского ПК.
2. Человек открывает попап расширения, вводит адрес шлюза и код и нажимает
   Pair. Код нормализуется как введён: пробелы обрезаются, регистр верхний,
   дефис необязателен (`ABCD-2345`).
3. Расширение обменивает код на токен моста (`POST /bridge/v1/pair`,
   `extension/src/pairing.ts`) и сохраняет его в `chrome.storage.local`,
   привязанным к device id, сгенерированному на этом ПК.
4. Кнопка Connect в попапе открывает исходящее WSS-соединение
   (`/bridge/v1?token=…`); рукопожатие — `bridge.hello` → `bridge.ready`.

Unpair удаляет токен. Отзыв устройства в панели моста заставляет шлюз отказать
токену (fail-closed), и соединение рвётся. Токен моста не появляется ни в
интерфейсе, ни в журналах, ни на странице.

## Сборка и установка

```sh
cd extension
npm install
node build.mjs        # или: npm run build
```

Сборка (`extension/build.mjs`) запускает `tsc` и копирует манифест и статические
страницы (`popup/`, `options/`, `confirm/`) в `dist-extension/` — это каталог для
load-unpacked. В Chrome или Edge откройте `chrome://extensions`, включите режим
разработчика и выберите «Загрузить распакованное расширение», указав
`dist-extension/`. Проверка типов без вывода: `npm run typecheck`
(`tsc --noEmit`). Требуется Node >= 24.11.

Расширение не входит в образ доски и не выкатывается вместе с ним: оно
устанавливается вручную на каждый клиентский ПК.

## Тесты

```sh
cd extension
npm test
```

Vitest с jsdom и подставленными портами (`extension/tests/`): без настоящего
Chrome, без настоящей сети. В фикстурах используются `example.com` и нейтральные
коды сопряжения.
