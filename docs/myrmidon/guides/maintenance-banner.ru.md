# Баннер обслуживания

> English version: [maintenance-banner.md](maintenance-banner.md)

Когда открыто окно обслуживания, плашка вверху доски показывает, что находится
на обслуживании и что это значит для прогонов. Плашка только информирует —
открытие и завершение окон выполняется на странице Instance → General; что
такое окно обслуживания и как его открыть, см.
[../design/maintenance-mode.md](../design/maintenance-mode.md).

Эта страница описывает агрегированную плашку, появившуюся в выпуске 1.6.1. До
неё баннер рисовал по строке на окно (группируя только окна агентов одного
вида, с версии 1.3); теперь баннер — всегда одна свёрнутая плашка.

## Свёрнутая плашка

Сколько бы окон ни было открыто — по одному на агента при пакетном обновлении
контейнеров плюс окна инстанса, компании и отдела — баннер остаётся одной
сворачиваемой плашкой вверху макета, обновляемой каждые 30 с. Видны окна,
касающиеся текущей компании: инстансовые — везде, более узкие — только в своей
компании. Сводная строка показывает:

- общее число открытых окон;
- число видов, на которые они группируются (тип области + состояние +
  причина);
- агрегированное состояние: `ending`, когда все окна завершаются, `draining`,
  пока хотя бы одно окно ждёт завершения идущих прогонов (с суммарным числом
  ещё выполняющихся прогонов или вариантом «сверх таймаута»), иначе `on`;
- границу «до» (строка `maintenanceBanner.endsBy`, плейсхолдер `{{time}}`) —
  самый поздний дедлайн освобождения среди всех окон, которые не
  завершаются. Фраза опускается, когда дедлайн неизвестен.

В свёрнутой сводке идентификаторы агентов не показываются — только счётчики.

## Развёрнутые детали

Развёрнутая плашка перечисляет по строке на вид окна: область, состояние,
самое раннее время начала и причину, плюс число окон и суммарное число побудок
в очереди этого вида. Два окна попадают в одну строку, только когда совпадают
тип области, состояние и нормализованная причина; идентификаторы агентов
вырезаются из причины до группировки, поэтому одна строка пакетного
обновления покрывает всю пачку. Для строк агентов идентификаторы отдельных
агентов видны по наведению и в строке «Идентификаторы агентов» внутри
развёрнутой строки — но не в свёрнутой сводке.

## Как читать состояния

- **on** — окно активно; новые прогоны приостановлены, а побудки ставятся в
  очередь (они доставляются, когда обслуживание заканчивается).
- **draining** — окно ждёт завершения уже идущих прогонов; метка показывает,
  сколько ещё выполняется, или сколько выполняется сверх таймаута при
  истёкшем освобождении.
- **ending** — окно закрывается.
