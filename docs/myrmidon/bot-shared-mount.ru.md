# Функция общего монтирования (Shared Mount)

## Обзор
Функция общего монтирования позволяет ботам получить доступ к общему каталогу с контролируемым доступом на чтение/запись. Это заменяет предыдущую систему, в которой каждый бот имел свою собственную копию общих данных с использованием жёстких ссылок, что не позволяло файлам, созданным одним ботом, быть видимыми для других.

## Конфигурация

### Настройки уровня инстанса
Функция общего монтирования настраивается на уровне инстанса через настройки инстанса. Доступны следующие опции:

- **enabled**: Включена ли функция общего монтирования для этого инстанса
- **hostPath**: Путь к хосту для общего каталога (по умолчанию `MYRMIDON_BOT_VOLUME_ROOT/shared`)
- **writable**: Могут ли боты записывать в общий каталог
- **allowedBots**: Список разрешённых ID ботов, которые могут получить доступ к общему каталогу

### Контроль доступа на уровне бота
Отдельным ботам можно предоставить доступ к общему каталогу через конфигурацию бота. Доступ предоставляется на основе настроек инстанса и наличия ID бота в списке разрешённых.

## Использование
Когда функция общего монтирования включена и у бота есть доступ, общий каталог будет смонтирован по адресу `/shared` в контейнере бота. Файлы, помещённые в этот каталог одним ботом, будут видны другим ботам, у которых есть доступ к общему каталогу.

## Миграция
При первом включении функции существующие копии с жёсткими ссылками от ботов будут перенесены в общий каталог для сохранения данных.
