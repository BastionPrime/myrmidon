# Дисклеймер Telegram (экран первого входа)

Это приложение — неофициальный клиент. Оно **использует Telegram API**
(официальную библиотеку TDLib) для подключения к сети Telegram и **не
аффилировано** с Telegram FZ-LLC.

Что это означает для вас:

1. **Использование Telegram API.** Соединение с сетью Telegram
   выполняется через публичный Telegram API с собственным идентификатором
   приложения (api_id), полученным на my.telegram.org. Требование
   Telegram к сторонним клиентам — явно и заметно информировать
   пользователей об использовании Telegram API (условия для сторонних
   клиентов, core.telegram.org/api/terms). Этот текст выполняет
   требование.

2. **Аккаунты под наблюдением.** По условиям Telegram аккаунты, входящие
   через неофициальные клиенты, автоматически ставятся под наблюдение
   серверов Telegram. Это может отражаться на доступных лимитах и
   рекомендациях безопасности вашего аккаунта.

3. **Что видит сервер Telegram:** номер телефона, IP-адрес, метаданные
   сообщений и (в обычных чатах, без секретных) содержимое переписки —
   сервер Telegram обрабатывает его по своей политике. Шифрование на
   устройстве касается только локальной базы TDLib
   (databaseEncryptionKey хранится в защищённом хранилище устройства).

4. **Секретные чаты** в этой сборке отключены (use_secret_chats=false).

5. **Регистрация новых аккаунтов не поддерживается** — только вход
   существующего номера.

6. **Поддержка.** При проблемах с учётной записью, кодом подтверждения
   или облачным паролем (2FA) обращайтесь к официальному клиенту
   Telegram; серверные ограничения не зависят от этого приложения.

Продолжая вход, вы подтверждаете, что прочитали и поняли этот текст.
